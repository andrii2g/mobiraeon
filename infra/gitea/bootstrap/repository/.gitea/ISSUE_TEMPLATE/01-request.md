Submitting this issue does not approve work or start an Agent. Do not include credentials.

## Desired outcome

What would you like to achieve, and who needs it?

## Why it matters

Describe the problem or benefit, with an example if useful.

## Scope and constraints

What should be included or excluded? Record relevant restrictions, priorities, or timing.

## Project and existing context

Identify the Project or repository. Link related Requests, an existing Initiative, documents, or examples when known.

## What success would look like

Describe observable outcomes. These are expectations for clarification, not a claim of acceptance.

## Open questions

What is uncertain or needs discussion? Write "None known" if appropriate.
